# Alumni Network Portal

A RESTful Alumni Network Portal developed using Java, Spring Boot, Spring Data JPA, and H2 Database.

## 📌 Project Description

The Alumni Network Portal is a backend application that allows alumni information to be stored, retrieved, updated, and deleted through REST APIs.

The project demonstrates CRUD operations using Spring Boot and Spring Data JPA.

## 🚀 Features

- Add new alumni
- View all alumni
- View alumni by ID
- Update alumni information
- Delete alumni
- Search alumni by name
- Search alumni by department
- Search alumni by company

## 🛠️ Technologies Used

- Java 17
- Spring Boot
- Spring Web
- Spring Data JPA
- H2 Database
- Maven
- REST API
- Postman
- Git & GitHub
